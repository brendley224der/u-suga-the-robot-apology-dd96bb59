A two-line robot confession: one sentence owning a specific mistake (watering a plastic fern for a week), one naming the lesson and the fix it will follow. Written by a small deterministic Python program that self-checks the gate (1–400 characters, exactly two lines) before writing `/output/entry.txt`.

## Run it

```sh
python3 main.py /output/entry.txt
```
